# Notes on Music

Local development

    npm run dev

Then visit the URL printed on your terminal, followed by /music.

For example:

    http://localhost:4321/music/

## Documentation

See the contents of the ./src/content/pages directory for all documentation.

## File and folder structure

* ideas.md is for general notes which can be useful for content, but not designed for public consumption just yet.
