# 1. Why are there twelve notes in an octave?

A string vibrating will create a note.

A string half the size will create the same note an octave higher.

A string double the size will create the same note an octave lower.

A(4) (the A above the middle C) is often 440 Hz, as adopted by the International Organization for Standardization (R16, 1975). [1]

A(3) is therefore 220 Hz
A(4) is 440
A(8) is 880

Therefore, the Hz difference between octaves is not always the same.

What is always the same is the mathematical relationship between 2 frequencies. For example, it is x2 for octaves.

A vibrating string produces sounds at different modes.

f1 = the frequency produced by the string at 1/1 its length
f2 = the frequency produced by the string at 1/2 its length
f3 = the frequency produced by the string at 1/3 its length
f4 = the frequency produced by the string at 1/4 its length
f5 = the frequency produced by the string at 1/5 its length
f6 = the frequency produced by the string at 1/6 its length

f1 is the fundamental note.
f2, 3, ... are overtones

f1 = fundamental
f2 = (fundamental x 2/1) octave
f3 = (f2 x 3/2)
f4 = (f3 x 4/3)
f5 = (f4 x 5/4)
f6 = (f5 x 6/5)

## Just intonation

Let's take the above and place them in order, imagining that f1 is 440 Hz, and f2 is 880 Hz, l:

f1 (440) ... f2 (880)

So if our scale had one note instead of twelve, it would be f.

Where does f3 fit in there?

f3 is 3/2 of f2, or 800 * 3/2 = 1,200 Hz. Let's move it down an octave (600) to fit in our scale:

f1 (440) ... f3 (600) ... f2 (880)

This is *not* the equal temperament scale which pianos use. That one is:

f1 (440, A(4)) ... f3 (587, D(5)) ... f2 (880, A(5))

For now we will stay on the just intonation scale.

so f4 is 4/3 of f3, so 600 * 4/3 = 800. Let's add that to our scale.

f1 (440) ... f3 (600) ... f4 (800) ... f2 (880)

let's keep going, adding f5 which is 5/4 of f4, so 800 * 5/4 = 1000. That's outside the range of our scale, so let's half it to 500, like this:

f1 (440) ... f5 (500) ... f3 (600) ... f4 (800) ... f2 (880)

Let's go on and fill up our just intonation scale with 8

C (Root) – Ratio 1:1 = 440 Hz
D (Major Second) – Ratio 9:8 = 495 hz
E (Major Third) – Ratio 5:4 = 550 Hz
F (Perfect Fourth) – Ratio 4:3 = 586.66 1/3 Hz
G (Perfect Fifth) – Ratio 3:2 = 600 Hz
A (Major Sixth) – Ratio 5:3 = 436.05 Hz
B (Major Seventh) – Ratio 15:8 = 489.81 Hz
C (Octave) – Ratio 2:1 = 523.26 Hz




Just intonation uses pure mathematical ratios derived from the natural harmonic series to create perfectly consonant chords, while equal temperament divides






f4 = (f3 x 4/3) perfect fourth
f5 = (f4 x 5/4) major third
f6 = (f5 x 6/5) minor third
