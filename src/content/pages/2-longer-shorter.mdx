The longer the string, the lower the pitch.

Compare these two strings:

<StringVisualV2 />
<StringVisual length={200} hz={440} />
<StringVisual length={100} hz={880} />
<StringVisual length={400} hz={220} />

A string half the size will create the same note an octave higher.

A string double the size will create the same note an octave lower.
