This website is designed to provide bite-sized snippets of information on interactive pages, on certain concepts of musical theory. I am not a musician but I find it easier to learn stuff if I make a website about it.

The content herein is free for your use, you can do whatever you want with it, it is released under the MIT license which you can find in the file ./LICENSE.

I can be contacted on [LinkedIn](https://www.linkedin.com/in/albertalbala/).

This website is built with [Astro](https://astro.build/). The source code can be found on [GitHub](https://github.com/alberto56/music).
